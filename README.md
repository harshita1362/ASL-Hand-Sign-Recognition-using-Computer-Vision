🤟 ASL Hand Sign Recognition

A real-time American Sign Language (ASL) hand sign recognition system built using computer vision and machine learning. The system detects hand gestures through a webcam and classifies recognized signs using a trained model.

🛠️ Tech Stack

- Python
- OpenCV
- MediaPipe
- cvzone
- Machine Learning

🔍 Key Features

- Real-time hand detection
- ASL hand-sign classification
- Webcam-based recognition
- Trained image-classification model
- Live prediction display

⚙️ Workflow

Webcam → Hand Detection → Image Processing → Model Prediction → Sign Recognition
